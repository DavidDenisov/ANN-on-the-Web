About this search

Search the paper's full corpus of 35,167,920 Wikipedia passages using its uploaded vector clusters.

Your query and embedding stay in this browser. The model and centroids load in a background worker when you open this page. Your browser retrieves the selected vector clusters and result text when you search. The host/CDN sees your IP address, request timing, cluster IDs and text-batch IDs. These can reveal semantic interests and likely results; local query processing does not hide these access patterns.

Passages are extracted from Wikipedia and credited to the linked articles and their contributors under the applicable CC BY-SA terms. Embeddings are provided by Narek Maloyan.

How search is measured

Results separate embedding time, centroid setup, vector retrieval and result-text loading. The model and centroids are reused for later searches; selected vector clusters are downloaded for each search. Decoded passage metadata stays in a limited memory cache until this page closes or reloads.
