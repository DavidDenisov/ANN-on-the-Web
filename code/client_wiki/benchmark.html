What is measured?

Source recovery@1 is the fraction of noisy queries whose original passage is the first result. Even a full scan may miss the original if noise moves another passage closer.

Each test runs one pass over its queries, loading its centroids once before timing. Query latency includes routing, cluster transfer, decompression, decoding and scoring; centroid loading and embedding are excluded.

The compression accuracy check uses four probes and one pass, with caching allowed only for cluster files. Centroids bypass browser caching. It keeps cluster membership fixed and does not report query latency.
